# Cómo contribuir a este proyecto

## Flujo de ramas

Por favor, nunca se trabaja sobre `main`. Siempre se crea una rama nueva
para trabajar con `switch -c nombre-rama`.

## Mensajes de commit

Se sigue el formato `tipo: descripción` siendo tipo:

- Un feat
- Un arreglo (fix)

## Cómo proponer un cambio

1. Crea una rama desde `main`.
2. Haz tus commits en ella.
3. Sube la rama: `git push -u origin nombre-de-la-rama`.
4. Abre una Pull Request en GitHub describiendo el cambio.
5. Espera la revisión antes de fusionar.

## Cómo clonar y ejecutar este proyecto

git clone git@github.com:USUARIO/ut2-git-python.git
cd ut2-git-python
Desde la terminal, si tienes vscode puedes ejecutar `code .` y accedes al proyecto
